# UniHome Frontend

React + Vite client for UniHome.

## Scripts

- `npm run dev` starts the local Vite server.
- `npm run build` creates the production build in `dist/`.
- `npm run preview` serves the production build locally.

## Folder notes

- `src/api/` contains backend API clients.
- `src/components/` contains reusable UI, layout, listing, and form components.
- `src/pages/` is split by public, student, owner, and admin flows.
- `public/` contains static assets copied directly into the build.
